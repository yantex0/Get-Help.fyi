# Guide Assumptions

---

## Assumptions & Terminology

1. All guides are **non-exhaustive**, so they will not explain everything but hopefully enough to get started.
2. All guides are created and tested on **Windows 11**.
3. All guides are using the default [Windows Terminal](https://learn.microsoft.com/en-us/windows/terminal/).
4. All guides are using [PowerShell 7.7+][ps-core].
5. All guides will use the below terminology for both **unique editions** of PowerShell as:

    | Edition            | Characteristics                             | Link                                     |
    | ------------------ | ------------------------------------------- | ---------------------------------------- |
    | PowerShell         | Newer, actively maintained, cross platform. | [PowerShell][ps-core]                    |
    | Windows PowerShell | Older, deprecated, Windows only.            | [Windows PowerShell][Windows-PowerShell] |
