# Update-Help

Downloads up-to-date help files for the [`Get-Help`](get-help.md) cmdlet to use.

## Usage

```powershell
Update-Help
```

## Notes

- `Update-Help` requires administrative privileges in PowerShell 6.0 and below, meaning Windows PowerShell and the very first release of PowerShell.
